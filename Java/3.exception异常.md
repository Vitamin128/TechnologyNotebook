##### 异常什么情况会导致程序崩溃
1. 在SpringBoot启动的过程中如果抛出一个异常，沿着调用链不断向上传递都没有程序员和Spring处理那么SpringBoot启动直接失败。
2. 在运行时期，如果没有手动处理异常和错误，一直向上抛出到程序的最高层，异常和错误不会导致SpringBoot整个进程的崩溃。
##### 关于异常的处理问题
1. 运行时异常也就是RuntimeEception。可以没有throws和catch，但是此异常会一直向上抛出，直到遇到RuntimeEception的父类或者此异常类型的catch捕获，如果一直向上抛出到最高层都没有被捕获，处理该任务的线程会终止然后在没有资源引用之后回收。
2. 但是一个函数中如果throw一个受检异常并且没有catch和函数头没有throws的话，这个程序在编译期间就无法通过，如果调用这个函数的调用方也不catch和throws的话同样也会编译失败。
