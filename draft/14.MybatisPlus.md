## 一、基础 CRUD 与持久层接口【P0：最高频】

- [ ] MyBatis-Plus 的定位
  - 理解它在 MyBatis 基础上增强通用数据操作，减少重复持久层代码。
- [ ] BaseMapper< T >
  - 为实体定义 Mapper，理解泛型实体与数据库表的对应关系。
- [ ] Mapper 注入
  - 将 Mapper 注册到 Spring 并注入业务组件，理解实际调用的是代理对象。
- [ ] 新增记录
  - 使用 insert 或 save 保存实体，检查主键生成和执行结果。
- [ ] 主键查询
  - 使用 selectById 或 getById 查询记录，处理不存在的情况。
- [ ] 条件列表查询
  - 使用 selectList 或 list 查询集合，区分无结果与执行失败。
- [ ] 单条查询
  - 使用 selectOne 或 getOne，明确结果可能为多条时的处理方式。
- [ ] 数量与存在性查询
  - 根据业务需要检查数量或是否存在，减少无必要的完整记录读取。
- [ ] 主键更新
  - 使用 updateById 更新记录，理解实际更新哪些字段。
- [ ] 条件更新与删除
  - 明确操作范围并检查执行结果，避免条件缺失。
- [ ] IService< T > 与 ServiceImpl
  - 掌握企业常见通用 Service 封装，区分数据操作与业务逻辑职责。
- [ ] 返回值与影响行数
  - 理解实体、集合、数量和布尔结果，不能把方法调用完成直接当作业务成功。
- [ ] saveOrUpdate
  - 理解基于主键判断的保存或更新，不将它等同于数据库原生原子 UPSERT。

## 二、Lambda 与条件构造器【P0：最高频】

- [ ] LambdaQueryWrapper
  - 使用实体方法引用构造查询条件，减少硬编码字段名。
- [ ] LambdaUpdateWrapper
  - 使用方法引用设置更新字段和筛选条件。
- [ ] QueryWrapper 与 UpdateWrapper
  - 理解字符串字段通常对应数据库列名，区分它与 Java 属性名。
- [ ] 等值与比较条件
  - 掌握 eq、ne、gt、ge、lt、le，匹配业务字段与参数类型。
- [ ] 动态条件
  - 使用 condition 参数控制条件是否加入，处理可选查询字段。
- [ ] 模糊查询
  - 掌握 like、likeLeft、likeRight 等方式，确认生成的匹配范围。
- [ ] 区间查询
  - 使用 between 或组合比较条件表达数值和时间范围。
- [ ] 集合查询
  - 使用 in、notIn，显式处理空集合和过大的集合。
- [ ] NULL 条件
  - 使用 isNull、isNotNull，理解 SQL NULL 与 Java null 的区别。
- [ ] AND 与 OR
  - 正确组合条件，避免 OR 改变整个查询范围。
- [ ] 条件分组
  - 使用 and、or、nested 等表达括号关系，并检查最终 SQL。
- [ ] 排序
  - 使用 orderByAsc、orderByDesc，处理动态排序字段的允许范围。
- [ ] 查询指定列
  - 使用 select 减少读取字段，理解部分字段实体的使用限制。
- [ ] Wrapper 生命周期
  - 为每次操作创建合适实例，避免跨请求、跨线程共享或错误复用。
- [ ] 链式调用
  - 使用查询和更新链式 API，理解条件构建与终结方法的执行时机。

## 三、实体与数据库映射【P0：最高频】

- [ ] 实体类职责
  - 用实体描述表结构和持久化字段，明确它与请求、响应对象的区别。
- [ ] @TableName
  - 显式配置表名，处理命名不一致、前缀和 Schema 等情况。
- [ ] @TableId
  - 标记主键字段并配置生成策略，确认 Java 类型与数据库类型一致。
- [ ] @TableField
  - 配置字段映射、持久化策略、填充和类型处理等属性。
- [ ] 下划线与驼峰
  - 理解数据库列名与 Java 属性名转换规则。
- [ ] 非数据库字段
  - 使用 exist=false 等方式排除辅助属性。
- [ ] 字段查询控制
  - 为不应默认查询的字段配置查询策略，理解自定义 SQL 的独立行为。
- [ ] Java 与 SQL 类型
  - 匹配整数、字符串、布尔值、时间和二进制等类型。
- [ ] 包装类型与默认值
  - 区分 null、0 和 false，避免基本类型默认值造成错误更新。
- [ ] 金额与精度
  - 使用匹配的 BigDecimal 和数据库精度，处理范围及舍入规则。
- [ ] 公共实体字段
  - 按团队约定组织 ID、时间、删除标记等公共属性，核对继承映射。
- [ ] 部分字段查询结果
  - 区分未查询字段与数据库真实空值，避免直接将查询结果用于覆盖更新。

## 四、更新策略与空值处理【P0：高频】

- [ ] 插入字段策略
  - 理解哪些字段会出现在 INSERT 中，以及数据库默认值何时能够生效。
- [ ] 更新字段策略
  - 理解 updateStrategy 对 null 和空字符串等值的处理。
- [ ] 局部更新
  - 只修改业务允许的字段，减少无关字段被覆盖。
- [ ] 将字段更新为 NULL
  - 使用明确的更新方式表达置空，区分置空与不修改。
- [ ] 请求字段存在性
  - 区分客户端未传字段、传 null 和传空字符串。
- [ ] Entity 与 Wrapper 更新
  - 理解实体字段、set 字段和 WHERE 条件各自参与的部分。
- [ ] 更新条件检查
  - 在可选条件缺失时明确处理，不让条件意外退化成大范围更新。
- [ ] 修改成功判断
  - 根据影响行数或返回结果处理记录不存在、条件不匹配等情况。
- [ ] 数值增减
  - 按版本使用合适 API 或自定义 SQL，减少先查再写引起的竞争。
- [ ] 全局与字段级策略
  - 核对局部配置与全局配置，避免为了一个字段改变所有实体的行为。

- [ ] 稳定排序

## 八、Spring 事务与业务一致性【P0：高频】

- [ ] @Transactional
  - 在合适的业务边界内组织多个数据库操作。
- [ ] 事务管理器与数据源
  - 确认 Mapper 使用的连接与 Spring 事务管理的资源一致。
- [ ] 事务提交与回滚
  - 理解正常返回、抛出异常和回滚规则对最终结果的影响。
- [ ] checked 与 unchecked 异常
  - 按 Spring 版本和配置确认回滚行为，必要时设置明确规则。
- [ ] 代理与内部调用
  - 排查同类内部调用等情况导致事务未按预期生效。
- [ ] 捕获异常与返回 false
  - 理解吞掉异常或方法返回失败标记不一定自动触发回滚。
- [ ] 传播行为
  - 根据业务理解 REQUIRED、REQUIRES_NEW 等事务关系。
- [ ] 隔离级别与并发
  - 区分事务隔离、锁和乐观版本控制各自解决的问题。
- [ ] 事务时长
  - 减少事务中长时间网络调用和无关处理，控制连接与锁占用。
- [ ] 数据库与外部系统
  - 为消息、缓存和外部调用设计一致性方案，明确本地事务覆盖范围。
- [ ] 并发唯一性
  - 结合数据库唯一约束处理竞争，不只依赖先查询再插入。

## 十、SQL 日志、测试与常见错误【P1：经常使用】

- [ ] SQL 日志配置
  - 查看 SQL 模板和参数，确认实际筛选与更新范围。
- [ ] 日志与最终执行行为
  - 结合参数、插件和数据库结果理解查询，不只看调用代码。

  - 排查扫描范围、配置类和依赖问题。

  - 检查方法定义、XML、资源打包和 SqlSessionFactory 配置。

  - 排查字段策略、条件、逻辑删除、版本冲突和事务提交。
- [ ] 分页未生效
  - 检查插件、解析依赖、分页参数和最终 SQL。
- [ ] 自动填充未生效
  - 核对处理器注册、字段名、类型、填充策略及调用方式。

  - 验证正常、空值、边界、重复和异常场景。

  - 使用匹配数据库或 Testcontainers，检查方言、约束和插件兼容性。
- [ ] SQL 分析工具
  - 按需要使用 P6Spy 等观察执行情况，考虑性能开销和日志数据范围。
