## 一、VM options 基础

- [ ] VM options 概念
  - 理解虚拟机选项用于配置 JVM 启动和运行行为，包括内存、垃圾回收、诊断、调试等。
- [ ] Java 程序启动流程
  - 理解启动器解析参数、创建 JVM、加载主类并调用 main() 的过程。
- [ ] VM options 生效范围
  - 理解 IDEA 运行配置中的参数作用于当前启动的 Java 进程。
- [ ] 应用 JVM 与 IDEA JVM
  - 区分项目运行配置的 VM options 与 IDEA 自身的虚拟机配置。
- [ ] VM options 与 Program arguments
  - 区分 JVM 参数与传入 main(String[] args) 的程序参数。
- [ ] VM options 与环境变量
  - 区分系统属性、操作系统环境变量，以及 JVM 从环境变量接收启动参数的机制。
- [ ] JVM 参数与业务配置
  - 理解 JVM 内存参数由虚拟机处理，业务属性需要应用或框架读取后才产生业务效果。
- [ ] 启动参数与运行期配置
  - 理解多数参数需要重启生效，只有部分参数支持运行期间调整。

## 二、参数分类与书写规则

- [ ] 标准参数
  - 认识 -D、-ea 等标准选项，理解它们与具体 JVM 实现扩展参数的区别。
- [ ] -X 参数
  - 认识 -Xms、-Xmx、-Xss 等额外选项，了解其支持情况依赖 JVM 实现。
- [ ] -XX 参数
  - 认识 HotSpot 高级选项，理解它们可能随版本变化。
- [ ] 布尔参数语法
  - 掌握 -XX:+参数名 表示启用、-XX:-参数名 表示禁用。
- [ ] 数值参数语法
  - 掌握 -XX:参数名=数值 的形式，按参数定义确认单位。
- [ ] 内存容量写法
  - 理解 -Xmx512m、-Xmx2g 等写法，以及容量与百分比配置的区别。
- [ ] 参数分隔与引号
  - 使用空格分隔选项；值包含空格时使用引号，并区分 IDEA 字段与终端的解析规则。
- [ ] 参数位置
  - 理解 JVM 选项通常位于主类或 JAR 名称之前，之后的内容通常作为程序参数。
- [ ] 重复参数与冲突
  - 避免重复或冲突配置，不把“后面的参数总能覆盖前面的参数”当作通用规则。

## 四、系统属性与 Java 读取方式

- [ ] -D 系统属性
  - 使用 -Dapp.mode=dev 设置系统属性，理解它本身不会自动改变业务逻辑。
- [ ] System.getProperty()
  - 使用 System.getProperty("app.mode") 读取属性，未设置时默认返回 null。
- [ ] 属性默认值
  - 使用 System.getProperty("app.mode", "local") 为缺失属性提供默认值。
- [ ] 属性类型转换
  - 理解系统属性以字符串保存，读取数字和布尔值时需要相应转换。
- [ ] System.setProperty()
  - 理解运行期间修改属性与启动时设置属性的区别，以及组件可能已经缓存属性值。
- [ ] System.getenv()
  - 使用 System.getenv("APP_MODE") 读取环境变量，区分它与 System.getProperty()。
- [ ] main() 参数读取
  - 使用 args 读取 Program arguments，并处理参数数量不足等情况。
- [ ] 时区配置
  - 了解 -Duser.timezone=Asia/Shanghai，区分 JVM 默认时区与业务显式指定的时区。
- [ ] 字符编码配置
  - 了解 Java 17 HotSpot 中 -Dfile.encoding=UTF-8 的用途，区分默认字符集、文件编码和控制台编码。

## 五、JVM 内存配置

- [ ] JVM 内存结构
  - 区分堆、线程栈、元空间、代码缓存、直接内存和其他本地内存。
- [ ] -Xms 初始堆大小
  - 理解初始堆容量与启动时内存规划的关系。
- [ ] -Xmx 最大堆大小
  - 理解最大堆容量约束 Java 对象所在的堆空间，不代表整个进程的最大内存。
- [ ] 初始堆与最大堆的搭配
  - 根据负载和资源限制选择容量，不把两者必须相等当作固定规则。
- [ ] -Xss 线程栈大小
  - 理解每个线程的栈空间与递归深度、线程数量和本地内存消耗的关系。
- [ ] MetaspaceSize
  - 理解它主要影响元空间触发垃圾回收的初始阈值，不等于固定预分配容量。
- [ ] MaxMetaspaceSize
  - 了解元空间容量上限与动态类加载、代理类生成之间的关系。
- [ ] MaxDirectMemorySize
  - 了解直接缓冲区内存限制，以及它不能限制全部堆外内存。
- [ ] ReservedCodeCacheSize
  - 了解 JIT 编译代码缓存及其容量配置。
- [ ] 堆内存与进程内存
  - 理解线程栈、元空间等额外开销，避免将全部可用内存分配给堆。

## 六、垃圾回收器与基础调优

- [ ] 垃圾回收目标
  - 区分吞吐量、暂停时间和内存占用，理解调优需要权衡。
- [ ] 默认垃圾回收器
  - 确认实际使用的收集器，不仅凭 JDK 版本推断默认选择。
- [ ] Serial GC
  - 了解串行收集器及 -XX:+UseSerialGC 的适用场景。
- [ ] Parallel GC
  - 了解并行收集器及 -XX:+UseParallelGC 的吞吐量取向。
- [ ] G1 GC
  - 了解 -XX:+UseG1GC、Region、混合回收和暂停时间目标。
- [ ] ZGC
  - 了解 Java 17 中 -XX:+UseZGC 的低延迟目标及平台支持条件。
- [ ] MaxGCPauseMillis
  - 理解暂停时间目标属于调优目标，不能保证每次暂停都不超过该值。
- [ ] GC 工作线程
  - 了解 ParallelGCThreads、ConcGCThreads 与可用 CPU、应用线程竞争的关系。
- [ ] 年轻代与晋升
  - 理解对象分配、存活和晋升流程，避免盲目固定 G1 年轻代大小。
- [ ] 显式 GC
  - 理解 System.gc() 的请求语义，以及 DisableExplicitGC 对行为的影响。
- [ ] GC 调优流程
  - 先测量分配速率、暂停和吞吐量，再修改参数并验证收益。

## 十四、常见问题与实践

- [ ] 参数填写错误
  - 排查拼写、大小写、单位、引号和不被当前 JDK 支持的选项。
- [ ] 配置了却没有生效
  - 检查启动配置、目标进程、实际参数、重启情况和框架配置优先级。
- [ ] 属性读取为 null
  - 检查属性名称，以及是否把系统属性、环境变量和程序参数混用。
- [ ] JVM 启动失败
  - 区分非法参数、资源不足、冲突选项与应用初始化失败。
- [ ] 中文乱码
  - 分别检查源文件、输入输出编码、默认字符集和控制台显示设置。
- [ ] 堆扩大后仍然 OOM
  - 分析泄漏、堆外资源、线程数量和容器限制，避免只增大 -Xmx。
- [ ] 本地参数与生产参数
  - 根据负载、资源预算和诊断需求设计配置，避免直接复制通用调优模板。
- [ ] 参数变更验证
  - 保留变更前后的吞吐量、延迟、GC 和内存数据，验证参数是否解决实际问题。
- [ ] 最小配置实践
  - 先保证默认配置可运行，再逐步添加有明确目的的选项。
- [ ] Java 参数读取练习
  - 编写 main()，分别用 args、System.getProperty()、System.getenv() 验证三个参数入口。
- [ ] 内存与诊断练习
  - 在独立练习程序中观察堆容量、GC、线程转储和 JFR，建立参数与运行现象的对应关系。
