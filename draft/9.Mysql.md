# 学习进度

> 主题：面向 Java 企业后端开发的 MySQL 知识体系。
>
> 数据库基线：MySQL 8.4、InnoDB；维护其他版本时，核对语法、默认行为与工具兼容性。
>
> Java 生态：JDBC、Spring Boot、Spring JDBC、MyBatis、MyBatis-Plus、Spring Data JPA、Hibernate，以及相关测试、迁移和数据集成工具。
>
> 使用方式：先选择一条持久层主线完成小业务，再根据问题补充知识；MyBatis 与 JPA 可以按项目选择。
>
> 勾选标准：能够解释用途，并通过 SQL、Java 代码、实验或案例分析验证理解；看过讲解不直接等于完成。
>
> 优先级：
> - P0：日常开发基础，优先建立完整使用能力。
> - P1：企业开发经常遇到，在实践中逐步掌握。
> - P2：按业务规模、项目架构或维护职责学习。
> - P3：底层原理、复杂优化与专项进阶。
>
> 建议实践主线：商品管理 → 订单查询 → 下单事务 → 并发扣库存 → 幂等处理 → SQL 优化 → 数据迁移 → 故障恢复。

## 任务一：商品 CRUD 与数据库约束【P0】

- [ ] 完成商品基础管理
  - 串联：表设计、数据类型、约束、Spring Boot 接入、选定的持久层框架。
  - 验收：可以新增、查询、修改和删除商品；重复编码被拒绝；金额准确保存；非法必填数据不能落库。

## 任务二：订单列表与统计查询【P0 → P1】

- [ ] 完成订单筛选、分页和销售统计
  - 串联：WHERE、JOIN、排序、分页、聚合和时间范围。
  - 验收：相同时间的订单排序稳定；关联后没有漏单或重复分页；统计结果与人工计算一致。

## 任务三：下单事务与异常回滚【P0】

- [ ] 完成订单和订单项的一致写入
  - 串联：本地事务、@Transactional、回滚规则和数据库约束。

  - 串联：联合索引、执行计划、数据分布和性能验证。
  - 验收：优化前后结果一致；记录计划、扫描量与耗时变化；能解释改善原因和新增索引的写入成本。
