
| 知识点    | 代表 API                     | 核心思想         |
| ------ | -------------------------- | ------------ |
| 不可变字符串 | String                     | 安全、简单        |
| 可变字符串  | StringBuilder/StringBuffer | 减少对象创建       |
| 抽象字符类型 | CharSequence               | 面向接口设计       |
| 字符输出抽象 | Writer                     | 统一输出模型       |
| 文件输出   | FileWriter                 | 写磁盘          |
| 内存输出   | StringWriter               | 写内存得到 String |
| 缓冲优化   | BufferedWriter             | 减少 IO 次数     |
