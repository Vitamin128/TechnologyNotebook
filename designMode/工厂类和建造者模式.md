==工厂模式==：将创建对象的各种复杂操作集成到工程类当中，创建者只需要指明要在建造者中需要创建那个对象，具体的创建操作被封装了起来

```
public interface Payment {
    void pay();
}
public class PaymentFactory {
    public static Payment create(String type) {
        return switch (type) {
            case "wechat" -> new WeChatPayment();
            case "alipay" -> new AliPayPayment();
            default -> throw new IllegalArgumentException("不支持的支付方式");
        };
    }
}
```

==建造者模式==：把需要赋值的参数放进Builder中，最后构建的时候统一构建
```
public class User {
    private final String name;
    private final int age;
    private final String email;
    // 只能通过 Builder 创建 User
    private User(Builder builder) {
        this.name = builder.name;
        this.age = builder.age;
        this.email = builder.email;
    }
    public static class Builder {
        private final String name; // 必填参数
        private int age = 18;       // 可选参数，有默认值
        private String email;      // 可选参数
        public Builder(String name) {
            this.name = name;
        }
        public Builder age(int age) {
            this.age = age;
            return this;
        }
        public Builder email(String email) {
            this.email = email;
            return this;
        }
        public User build() {
            if (name == null || name.isBlank()) {
                throw new IllegalArgumentException("姓名不能为空");
            }
            if (age < 0) {
                throw new IllegalArgumentException("年龄不能为负数");
            }
            return new User(this);
        }
    }
}
```
